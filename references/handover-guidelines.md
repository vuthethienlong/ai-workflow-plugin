# Handover guidelines

Before resuming, read available summaries, decisions, review findings, approval records, and handovers. If absent, state what context is unavailable and ask only for critical missing inputs.

Use [task-handover.md](../templates/task-handover.md) as a portable context note. It is manual artifact transfer, not native Orca trace support or an automatic session memory feature. Always state `NEXT_EXPECTED_STEP`.
